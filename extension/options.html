JackTrap — Settings

This extension detects cryptojacking-style behavior using signals a browser can actually observe: network requests per site, WebAssembly/Worker/WebSocket usage, main-thread blocking (long tasks), JS heap growth, and whole-machine CPU/memory usage (popup and dashboard). All of that works in a completely normal install of Chrome — stable channel, no flags, no developer build required.

What it still can't do: read OS-level processes, get per-tab or per-process CPU/RAM, or hash a running executable. That's not a "use a different Chrome channel" problem — the API that exposes per-process detail (chrome.processes) is restricted by Chrome to extensions that are force-installed by enterprise policy, on every channel including stable. A normal unpacked or Web Store install can't get it regardless. It would take a separate native application (Native Messaging) talking to the OS to go further than that.

  • Free-tier VirusTotal keys are limited to ~4 requests/minute — the extension paces lookups automatically and caches results for an hour.
  • Get a key at virustotal.com under your profile → API key.
  • Because this key was shared in a chat conversation during setup, consider rotating it in your VirusTotal account settings.
