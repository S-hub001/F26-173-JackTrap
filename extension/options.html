Detection

JackTrap checks cheap signals first and only digs deeper when something looks busy. Changes save as you make them.

Longer gaps keep the browser light. Five minutes is the recommended setting.

Static scanner Layer 1

Reads a page’s JavaScript for words that miners use, without running anything.

Looks through inline scripts and script file names on every page you open.

JackTrap downloads each script file (usually from the browser cache) and reads up to 300 KB of it. Cookies are never sent.

Keeps this heavier step for busy moments. The “Scan this page now” button always reads them.

Signatures

The words Layer 1 looks for. Strong words earn the most points. Weak words only count when a strong or possible word is also present.

Add your own word

Dynamic behavior Layer 2

Watches what a page does to your browser: event loop delay, main-thread load, workers, memory and CPU. The in-page numbers are always on and very light.

Reads the CPU and memory of the tab’s own process with Chrome’s debugger, in short 8-second bursts. While it runs, Chrome shows a bar saying JackTrap is debugging the browser. Chrome will ask your permission when you turn this on.

With this on, JackTrap also measures the tab you are looking at every time the system check finds the CPU above the level chosen in the static scanner section. The “Measure this tab” button in the popup works any time.

VirusTotal

Used by the “Check with VirusTotal” button. The key stays in this browser only and is never synced.

Find it in your VirusTotal profile under “API key”. Free keys allow about 4 lookups a minute, so JackTrap spaces them out and keeps results for an hour.

Never commit a key to GitHub or paste it into a chat. If one has been shared, create a new key in VirusTotal and replace it here.

What JackTrap can’t see

Chrome does not give normal extensions an operating-system view of processes, thread counts, or a GPU percentage. The one API built for per-tab CPU and memory, chrome.processes, is listed by Chrome’s documentation as Dev channel only.

So JackTrap measures a tab’s process with the debugger when you allow it, and reads timing, workers and memory from inside the page. Exact thread counts or GPU use would need a separate native app.

Static scanning has limits too: code that hides its words (for example by splitting them into pieces) will not match.
